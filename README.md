# John Wright-Nyingifa

**Design engineer. I design the product and write the code that ships it.**

Seven years designing software, four of them in crypto and autonomous systems. I don't stop at the mockup. I build the thing, put it in front of real users, and design against what actually breaks: the failed payment, the empty state, the permission someone doesn't have.

The question I keep returning to: when software acts on its own, how do you give a person real visibility into it, and real control?
