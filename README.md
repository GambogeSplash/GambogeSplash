# Hi, I'm John

**Product designer who ships. I design the product, then write the code that ships it.**

I'm a designer in Lagos with seven years behind me, four of them in crypto and autonomous systems. I design payments, commerce, and AI products, and I don't hand them off and hope. I build the thing, put it in front of real people, and design against what actually breaks: the failed charge, the empty state, the permission someone doesn't have.

The question I keep returning to is this: when software acts on its own, how do you give a person real visibility into it, and real control? Most of my work is some version of that. Money that moves itself. Agents that decide. Infrastructure that fails quietly.

Right now I'm moving from product design into design engineering. For me that means the React and TypeScript that ships, not just the Figma. I lean on AI tools like Claude Code and Cursor for velocity, and I make a point of understanding the code I ship.

## How I work

I write the React and TypeScript that ships, not just the Figma. Design systems, accessible implementation, Figma to production. The unglamorous states, errors, empty, loading, the permission someone doesn't have, are where I spend my real design time, because that's where trust is won or lost.
