# Hi, I'm John

**Design engineer. I design the product, then write the code that ships it.**

Seven years designing software, four of them deep in crypto and autonomous systems. I've shipped more than a dozen live products end to end, on my own: the research, the interface, the motion, and the React and TypeScript running in production. Most designers stop at the handoff. I deleted the handoff.

I build at the edge of what's new. AI agents that take payments mid-conversation. Stablecoin rails that settle in minutes. On-chain marketplaces. WebGL worlds. One question runs through all of it: when software acts on its own, how do you give a person real visibility into it, and real control?

I move fast because I use AI tools like Claude Code and Cursor the way a senior engineer does, and I can account for every line that ships.

## How I work

I write the React and TypeScript that ships, not just the Figma. Design systems, accessible implementation, Figma to production. The unglamorous states, errors, empty, loading, the permission someone doesn't have, are where I spend my real design time, because that is where trust is won or lost.

**Stack** TypeScript · React · Next.js · Tailwind · Figma · Solidity
